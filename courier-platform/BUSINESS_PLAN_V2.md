# CourierPlatform — Бизнес-план v2.0
## «Лучшее у лучших. Старт с малого города.»

---

# РЕЗЮМЕ

**Продукт:** Платформа мгновенной доставки для малых городов (50–300 тыс. жителей)
**Модель:** Маркетплейс — соединяем курьеров с заказчиками без собственного штата
**Стратегия:** Захватить 1 город → стать монополистом → масштабироваться
**Горизонт:** 12 месяцев до операционной прибыли
**Нужные инвестиции:** 1,200,000 ₽ на запуск и первые 6 месяцев

---

# ЧАСТЬ 1. ПРОБЛЕМА

## Что происходит в малом городе прямо сейчас

В городе с населением 100,000 человек:

- Ресторан нанимает 1–2 курьеров на зарплату → простой в «тихие» часы,
  нехватка в пиковые
- Цветочный магазин теряет заказы, потому что некому отвезти букет
- Аптека не может сделать срочную доставку лекарств пожилым
- Человек хочет передать документы коллеге через весь город —
  нет простого инструмента
- Курьеры работают в одном агрегаторе, привязаны к расписанию,
  зарабатывают мало

**Крупные игроки (Яндекс, Glovo, Wolt) в малые города не идут** —
для них это нерентабельно. Рынок свободен.

# ЧАСТЬ 2. РЕШЕНИЕ

## Концепция: «Uber для любой доставки»

Простая идея: **любой человек с транспортом** может стать курьером.
**Любой бизнес или человек** может отправить что угодно за 15–20 минут.

### Три принципа продукта

```
1. ПРОСТОТА    — 3 нажатия от идеи до оформленного заказа
2. СКОРОСТЬ    — курьер принимает заказ за < 60 секунд
3. ПРОЗРАЧНОСТЬ — клиент видит курьера на карте в реальном времени
```

### Что берём у лучших мировых игроков

| Игрок | Что заимствуем |
|---|---|
| **Wolt** | Минималистичный UI, цена видна ДО заказа, высокое качество UважнееUX |
| **Lalamove** | Любой тип груза (не только еда), мгновенный расчёт цены |
| **DoorDash** | Прозрачный заработок курьера, «Dashpass»-подписка для бизнеса |
| **Uber** | Автоматический подбор ближайшего курьера без диспетчера |
| **Glovo** | Категории «всё что угодно» — еда, аптека, цветы, посылки |
| **Shipday** | Простая панель для бизнеса — без обучения, подключился за 5 минут |

| Показатель | Мегаполис | Малый город (наш выбор) |

# ЧАСТЬ 4. ПРОДУКТ

## MVP — что входит в первую версию

### Для клиента
- Регистрация через телефон (1 шаг, SMS-код)
- Создание заказа: откуда → куда → что везти → цена → оформить
- Цена рассчитывается мгновенно до нажатия «заказать»
- Отслеживание курьера на карте в реальном времени
- История заказов
- Оценка курьера после доставки

### Для курьера
- Регистрация + верификация (фото, телефон)
- Кнопка «Онлайн / Офлайн»
- Лента доступных заказов с сортировкой по расстоянию
- Маршрут: забрать → доставить
- Счётчик заработка за день/неделю
- Вывод денег (еженедельно)

### Для бизнеса
- Личный кабинет: создавать заказы, видеть историю, статистику
- API (для интеграции с кассой или сайтом)
- Уведомления: «Курьер принял», «Доставлено»

### PWA — приложение без App Store
Устанавливается прямо из браузера на iPhone и Android.
Работает как нативное приложение. Сохраняет 30% на разработку.

## Что откладываем на v2

- Встроенная оплата картой (v1 — наличные/перевод)
- Чат клиент–курьер (v1 — звонок по телефону)
- Программа лояльности
- Мультигородность

# ЧАСТЬ 5. БИЗНЕС-МОДЕЛЬ

## Источники дохода

### 1. Комиссия с каждой доставки — 15%

```
Стоимость доставки = 50 ₽ + 20 ₽ × км
Пример (4 км): 50 + 80 = 130 ₽
  └─ Платформа: 19.5 ₽
  └─ Курьер:   110.5 ₽
```

Почему 15%, а не 25–30% как у конкурентов:
- Курьеры зарабатывают больше → они лояльны к нам
- Бизнесу выгоднее → легче переключиться с текущего решения
- Когда мы монополисты в городе — можно поднять до 18–20%

### 2. Бизнес-подписка — 2,990 ₽/месяц

Для ресторанов и магазинов:
- Приоритет в очереди курьеров
- Дашборд с аналитикой доставок
- API-доступ
- Персональный менеджер (чат)
- Первые 30 дней бесплатно

### 3. Срочная доставка — наценка +50%

Отдельная категория «Срочно, за 10 минут» — курьер получает приоритетный
заказ с повышенной ставкой. Клиент платит надбавку 50%.

# ЧАСТЬ 6. МАРКЕТИНГ

## Принцип: «Сначала курьеры — потом клиенты»

**Классическая ошибка стартапов:** рекламируют клиентам, когда курьеров нет.
Клиент заходит — видит «нет курьеров» — уходит навсегда.

**Правильная последовательность:**
```
Шаг 1: Набираем 30–50 курьеров → Шаг 2: Запускаем рекламу клиентам
```

| Листовки в универах | «Зарабатывай 2–4 часа в день» | 5,000 ₽ |

## Позиционирование

```
Не «ещё одна доставка еды»

А: «Отправь что угодно, куда угодно — за 15 минут»
```

**Слоган:** *«Наш город. Наша доставка.»*

Акцент на локальности — это то, чего Яндекс и Glovo никогда не смогут
дать: «Это сделано для вашего города людьми из вашего города».

# ЧАСТЬ 7. ОПЕРАЦИОННАЯ МОДЕЛЬ

## Как всё работает без офиса

| Процесс | Как решаем |
|---|---|
| Верификация курьеров | Фото паспорта + селфи через приложение (автоматически) |
| Поддержка клиентов | Telegram-бот + чат в приложении (1 оператор) |
| Конфликты | Автоматические компенсации до 500 ₽ без разбирательств |
| Выплаты курьерам | Раз в неделю на карту (самозанятые) |
| Документы | Договор оферты, самозанятость через «Мой налог» |

## Юридическая схема

```
Платформа — ИП или ООО на УСН 6%
Курьеры — самозанятые (налог 4–6%, чек через приложение)
Бизнес — любая форма, договор оферты
```

Это **самая лёгкая и законная схема** в РФ на сегодня.
Никаких трудовых договоров с курьерами — только гражданско-правовые отношения.

# ИТОГ

**Почему это сработает:**

1. **Рынок свободен** — конкуренты в малые города не идут
2. **Простота** — продукт понятен с первого взгляда
3. **Выгода для всех** — клиент платит меньше, курьер зарабатывает больше,
   бизнес экономит на штате
4. **Низкий порог** — MVP уже написан, запуск через 4–6 недель
5. **Эффект первопроходца** — кто первый в городе, тот и монополист
