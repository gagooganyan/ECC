# CourierPlatform — Бизнес-план и маркетинговый сценарий

---

## 1. ИДЕЯ И КОНЦЕПЦИЯ

### Суть проекта
**CourierPlatform** — это двусторонний маркетплейс доставки, где:
- **Заказчики** (рестораны, магазины, компании, частные лица) публикуют задачи на доставку
- **Курьеры** (фрилансеры) видят эти задачи в реальном времени и принимают их

Отличие от Яндекс.Доставки или Delivery Club: **платформа не держит собственных курьеров**. Мы — технология, а не логистическая компания. Курьеры — независимые подрядчики.

---

## 2. ПРОБЛЕМА

| Кто страдает | Боль |
|---|---|
| **Ресторан** | Нет постоянного потока курьеров; собственный курьер стоит 45,000 ₽/мес + налоги |
| **Магазин** | Нерегулярные заказы — держать штат невыгодно |
| **Частный человек** | Нет инструмента быстро отправить посылку в другой конец города |
| **Курьер** | Нет одного приложения, где видно все заказы с рынка; приходится работать через несколько агрегаторов |

---

## 3. РЕШЕНИЕ

**Единая open-платформа**, работающая в реальном времени:

```
Заказчик создаёт заявку → Платформа мгновенно рассылает курьерам
→ Свободный курьер принимает → Заказчик видит трекинг → Доставлено
```

Три ключевых преимущества:
1. **Скорость** — заявка уходит к ближайшим курьерам за секунды (WebSocket)
2. **Гибкость** — любой тип груза (еда, документы, посылки, цветы)
3. **Прозрачность** — заказчик видит курьера на карте, получает оценку

## 4. ЦЕЛЕВАЯ АУДИТОРИЯ

### Сегмент A — Рестораны и кафе (B2B)
- Малый и средний ресторанный бизнес без собственных курьеров
- Кафе с 20–200 заказами в день
- Облачные кухни (dark kitchens)

### Сегмент B — Ритейл и сервис (B2B)
- Цветочные магазины, аптеки, небольшие интернет-магазины
- Офисы (доставка документов, образцов)
- Химчистки, ателье, ремонтные мастерские

### Сегмент C — Частные лица (B2C)
- Люди, которым нужно передать вещь, посылку, ключи
- «Мама прислала пирожки, надо забрать с другого конца города»
- Курьерская замена такси для грузов

### Сегмент D — Курьеры (Supply side)
- Студенты, ищущие подработку
- Велосипедисты и самокатчики
- Бывшие сотрудники агрегаторов, которым надоела их политика
- Люди с авто, ищущие дополнительный доход

## 5. БИЗНЕС-МОДЕЛЬ

### Монетизация (Revenue Streams)

| Источник дохода | Механика | Прогноз % выручки |
|---|---|---|
| **Комиссия с заказа** | 15% от стоимости доставки | 75% |
| **Подписка для бизнеса** | 2,990 ₽/мес — приоритет, аналитика, API | 15% |
| **Выделенный курьер** | Курьер «под ключ» для 1 бизнеса на день | 7% |
| **Белый ярлык (White Label)** | Лицензия платформы под брендом клиента | 3% |

### Формула цены доставки

```
Стоимость = 50 ₽ (базовая) + 20 ₽ × км
Комиссия платформы = 15% от суммы
Курьер получает = 85% от суммы
```

**Пример:** Доставка 5 км = 50 + 100 = **150 ₽**
- Платформа: 22.5 ₽
- Курьер: 127.5 ₽

## 6. СЦЕНАРИЙ ИСПОЛЬЗОВАНИЯ (User Journeys)

### Сценарий 1 — Ресторан «Домашняя кухня»

> *Владелец Армен, 42 года, Ереван. Открыл облачную кухню на 80 заказов в день. Раньше нанимал 2 курьеров — это 90,000 ₽/мес + простой в тихие часы.*

1. Армен регистрирует ресторан в платформе за 5 минут
2. Интегрирует через API с кассой (или вводит вручную)
3. При каждом заказе клиента система автоматически создаёт заявку на доставку
4. Ближайший свободный курьер принимает в течение 2–3 минут
5. Армен видит трекинг на панели управления
6. Платит только за доставки, которые были совершены

**Экономия:** 90,000 ₽ → ~18,000 ₽ при том же объёме ✅

---

### Сценарий 2 — Курьер Давид

> *Давид, 24 года, студент. Хочет зарабатывать 2–4 часа в день между парами.*

1. Скачивает приложение / открывает веб-версию
2. Регистрируется, загружает фото
3. Нажимает «Онлайн»
4. Видит заявки на карте — берёт ту, что по пути
5. Нажимает «Принял», едет на пикап, нажимает «Забрал», доставляет, нажимает «Доставил»
6. Деньги начисляются автоматически на баланс
7. Выводит раз в неделю на карту

**Заработок:** 4 ч × 6 заказов × 127 ₽ = ~3,000 ₽/день ✅

---

### Сценарий 3 — Частный заказ (Карине → маме)

> *Карине, 28 лет, нужно отправить букет маме на день рождения через весь город.*

1. Открывает сайт, вводит откуда/куда
2. Видит цену: 150 ₽
3. Оплачивает картой, курьер прибывает через 8 минут
4. Мама получает цветы с запиской

## 8. МАРКЕТИНГОВАЯ СТРАТЕГИЯ

### Фаза 1 — Запуск (Месяцы 1–3): «Заполнить рынок курьерами»

**Цель:** 100 активных курьеров в городе запуска

Инструменты:
- Листовки в университетах («Подрабатывай 2–4 часа в день»)
- Таргет ВКонтакте/Instagram на студентов 18–25 лет
- Реферальная программа: «Приведи друга-курьера — получи 500 ₽»
- Партнёрство с велопрокатами и самокат-компаниями

**Бюджет фазы:** 150,000 ₽

---

### Фаза 2 — Рост (Месяцы 2–6): «Привлечь бизнес»

**Цель:** 30 ресторанов/магазинов-партнёров

Инструменты:
- Прямые продажи: менеджер обходит рестораны и предлагает 30 бесплатных доставок для теста
- Кейс-стади: «Как кафе сэкономило 70,000 ₽/мес»
- SEO + контент: «Как организовать доставку для малого бизнеса»
- Google/Яндекс реклама: «Курьер для ресторана без штата»

**Бюджет фазы:** 300,000 ₽

---

### Фаза 3 — Масштабирование (Месяцы 6+): «Сарафанное радио»

- Программа лояльности для постоянных заказчиков
- Отзывы и рейтинги (прозрачность = доверие)
- B2B подписка с дашбордом аналитики
- Выход в 2–3 новых города

## 13. ТЕХНИЧЕСКИЙ СТЕК (краткий обзор)

Выбраны технологии с минимальным порогом входа и максимальной надёжностью:

- **Backend:** Node.js + Express — быстрый старт, большая экосистема
- **БД:** SQLite → PostgreSQL при масштабировании — без дополнительных сервисов на MVP
- **Real-time:** Socket.io — WebSocket для мгновенной рассылки заказов курьерам
- **Авторизация:** JWT — stateless, масштабируется горизонтально
- **Хостинг MVP:** Railway / Render / VPS 1,500 ₽/мес
