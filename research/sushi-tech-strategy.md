# Технологическая стратегия: Суши Рама & Bearloga
## Модель IT-компании в ресторанном бизнесе (по принципу Додо Пиццы)

---

## 1. Философия: Мы не ресторан — мы IT-компания

Додо Пицца доказала: в современном фудсервисе побеждает не тот, у кого лучший рецепт, а тот, у кого лучшие **системы, данные и технологии**. Еда — продукт. Технологии — конкурентное преимущество.

**Ключевой принцип:** Суши Рама и Bearloga — это **технологические платформы** по доставке суши, упакованные в бренд.

### 3.2 Стек технологий (рекомендация)

**Быстрый старт (год 1):**
- **POS:** iiko или r_keeper + интеграция с доставкой
- **CRM/Лояльность:** Mindbox или Convead
- **Доставка:** собственные курьеры + API-интеграция с Яндекс.Еда / Delivery Club
- **Аналитика:** Google Looker Studio поверх PostgreSQL
- **Приложение:** PWA (прогрессивное веб-приложение) — быстрее и дешевле нативного

**Масштаб (год 2-3):**
- Собственная мобильная платформа (iOS + Android)
- ML-модель предсказания спроса
- Автоматическое управление стопами (stop-list)
- Система оценки качества через фото с кухни

## 4. Два бренда — одна платформа

### Архитектура двойного бренда

```
              ТЕХНОЛОГИЧЕСКАЯ ПЛАТФОРМА
                        │
          ┌─────────────┴─────────────┐
          │                           │
    СУШИ РАМА                    BEARLOGA
    (позиционирование:          (позиционирование:
     доступность,               премиум/атмосфера,
     скорость, объём)           авторские роллы)
          │                           │
    Общие ресурсы:             Собственные модули:
    - Логистика                - Отдельное меню
    - Закупки                  - Отдельный брендинг
    - Аналитика                - Своя аудитория CRM
    - IT-инфраструктура        - Ценовой сегмент выше
```

**Преимущество:** Общие IT-затраты делятся на два бренда. Эффективность x2.

### Разделение аудитории

| Параметр | Суши Рама | Bearloga |
|----------|-----------|----------|
| Средний чек | 600–1000 ₽ | 1200–2000 ₽ |
| Частота заказов | Высокая (1–2 раза/нед) | Средняя (1–2 раза/мес) |
| Канал | Доставка 80%, зал 20% | Зал 50%, доставка 50% |
| Ключевой триггер | Скорость + цена | Впечатление + качество |

## 5. Продуктовая стратегия

### 5.1 Метрики Dodо-style (ежедневный мониторинг)

```
ОПЕРАЦИОННЫЕ (каждые 15 минут):
├── Время приготовления заказа (цель: <12 мин)
├── Время доставки (цель: <40 мин)
├── % заказов в срок (цель: >95%)
└── Рейтинг точки в реальном времени

БИЗНЕС (ежедневно):
├── Выручка по каналам (доставка / зал / агрегаторы)
├── Средний чек по бренду
├── Конверсия из корзины в заказ
└── CAC (стоимость привлечения клиента)

КАЧЕСТВО (по каждому заказу):
├── NPS после доставки (SMS/Push)
├── % возвратов и жалоб
└── Фото блюд с кухни (контроль стандарта)
```

### 5.2 Принцип "Додо-камеры"

Додо первыми установили веб-камеры на кухнях — открытость как маркетинг.

**Для нас:** Онлайн-трансляция приготовления суши на сайте/в приложении.
Это решает сразу:
- Доверие клиента к свежести
- Контроль качества в реальном времени
- Вирусный маркетинг (люди делятся)

## 6. Цифровые каналы и лояльность

### 6.1 Собственное приложение vs агрегаторы

| Канал | Комиссия | Контроль данных | Приоритет |
|-------|----------|----------------|-----------|
| Яндекс.Еда / DC | 25–35% | Нет | Трафик |
| Собственное приложение | 0% | Полный | Прибыль |
| Сайт | 0% | Полный | Прибыль |
| Телеграм-бот | 0% | Полный | Быстрый старт |

**Стратегия:** Агрегаторы — для привлечения. Собственный канал — для удержания.

**Конверсия:** При первом заказе через агрегатор → предложить скидку 10% на следующий заказ через приложение.

### 6.2 Программа лояльности

```
Уровни лояльности:
├── Гость (0–4 заказа): базовые условия
├── Завсегдатай (5–19 заказов): +5% кешбэк, приоритет доставки
├── Ролл-мастер (20–49 заказов): +10% кешбэк, эксклюзивные позиции
└── Легенда (50+ заказов): +15% кешбэк, именные предложения, preview новинок
```

## 7. Операционная система (стандарты как код)

### 7.1 Принцип "рецепт — это алгоритм"

Каждый ролл = детерминированный процесс:
- Граммовка фиксирована (весы с интеграцией в систему)
- Время приготовления — таймер на KDS
- Температура хранения — IoT-датчики в холодильниках
- Фото эталона на каждой станции

### 7.2 Управление стоп-листом в реальном времени

Когда заканчивается лосось → система автоматически:
1. Убирает позиции со стоп-листа во всех каналах
2. Уведомляет менеджера
3. Предлагает замену клиенту при оформлении заказа

### 7.3 Предсказание спроса (ML)

На основе:
- История заказов (день недели, время, погода, праздники)
- Данные о доставке по зонам
- Акции и маркетинговые кампании

→ Автоматическое планирование заготовок на смену

## 10. Ключевые принципы (манифест)

1. **Данные важнее интуиции** — каждое решение обосновано метриками
2. **Стандарт воспроизводим** — что работает в одной точке, работает везде
3. **Скорость — уважение к клиенту** — время ожидания сокращается через технологии
4. **Открытость строит доверие** — клиент видит, как готовится его еда
5. **Платформа масштабируется, ресторан — нет** — мы строим систему, а не точку
